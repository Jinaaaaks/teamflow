
# TeamFlow 🩵🌱

TeamFlow is a mini task management web app built to practice real-world Git workflows and clean frontend development.

The project focuses on understanding how teams work with Git branches, commits, merges, and pull requests while building a simple but polished Kanban-style task board.

---

## ✨ Features

- Add new tasks
- Organize tasks into:
  - Todo
  - In Progress
  - Done
- Move tasks between columns
- Delete tasks
- Live task counters per column
- Clean baby blue & mint pastel UI
- Responsive, card-based layout

## 🔀 Git Workflow Used

This project was developed using a team-style Git workflow:

- `main` branch for stable code
- Feature branches for each task or UI change
- Regular commits with clear messages
- Branch merging and conflict resolution
- GitHub used for remote repository and pull requests

Example branches:
- `feature-add-task`
- `feature-task-status`
- `ui-pretty-board`
- `chore-readme-update`
