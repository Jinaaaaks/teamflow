# TeamFlow

TeamFlow is a mini task management web app built to practice real-world Git workflows.

## Purpose
- Learn Git branching and merging
- Simulate team collaboration
- Build clean, understandable features

## Tech Stack
- HTML
- CSS
- JavaScript

## Git Workflow
- main branch for stable code
- feature branches for development
- frequent commits

## Features
- Add tasks
- Move tasks between Todo, In Progress, Done
